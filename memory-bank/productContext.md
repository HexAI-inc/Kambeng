## Project Description

A mobile-first crowdfunding web app for The Gambia with donation, campaign management, admin moderation, and proof-of-expenditure workflows.



## Architecture

Next.js frontend with shared design tokens, Ant Design components, responsive card/table fallbacks, React Query, and server-side auth guards; backend FastAPI API with JWT auth, logging, and campaign/admin endpoints.
